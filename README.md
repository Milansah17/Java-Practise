# Java Practice Programs

Beginner Java programs written in IntelliJ IDEA while learning Java and problem solving.

## Topics
- **basics:** sum, functions, loops, multiplication table
- **number-programs:** prime, palindrome, Armstrong, factorial, Fibonacci, GCD, LCM, reverse, sum of digits
- **arrays:** search, traversal, sum, reverse, palindrome, delete, sorted check, max/min, 2D arrays
- **patterns:** star pyramids and patterns

## How to run
Open any file in IntelliJ IDEA (or any Java IDE) and run its `main` method.
The programs in `arrays` use `ArrayUtility.java`, so keep them together in that folder.
